# Club Match Secretary Manager

Standalone club match secretary template for managing fixtures, players, availability, team sheets, results, league tables and printable reports.

## How To Open

Double-click `index.html`.

No install is needed. No server, Node.js, paid database or external login service is required.

## Saving

All data saves in the browser using localStorage on the device being used.

## Print And Export

Each main section includes Print and Export PDF buttons. Export PDF uses the browser print dialog: choose "Save as PDF".

CSV export is included for:

- Fixtures
- Members
- Availability
- Match Results
- League Table

The Reports section includes printable report views for team sheets, fixtures, members, availability, results, league tables and tournament draws.
